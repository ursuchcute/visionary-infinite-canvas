# 待测试

- Hosted 客户端交付确认：主站 bootstrap 未下发 `imageDeliveryAck` 或值为 false 时，图片恢复应保持原行为且不请求新接口；值为 true 时，前台生成或刷新恢复的图片必须先把 Blob 与包含目标节点的画布快照写入 IndexedDB，再 POST `/api/canvas/v1/images/delivery-ack`，接口成功后才能清理本地 operation。模拟 ACK 断网、401、5xx 或超过 10 秒无响应时，本地 operation 应保留交付检查点且下轮只用同一 `clientOperationId` 重试 ACK，不能再次插入恢复节点、重复生成或扣分；模拟服务端已写入但响应丢失时，重复 ACK 应安全成功。上游生成失败和文本任务不应发送图片 delivered ACK。
- Hosted v0.12.0：空画布中央显示灰色「双击画布自由生成」提示；任意节点创建后提示隐藏，平移和缩放时提示仍固定在可视区域中央。图片任务修改模型、清晰度、比例、质量和数量后，新建图片节点应沿用最近一次合法参数；文本任务模型独立沿用，且不会与图片参数互相污染。参考图缩略图悬停预览应显示在节点输入面板、连线和其他画布浮层上方，靠近视口边缘时仍完整可见；删除参考图继续自动断开对应连线。
- Hosted 本地联调：双击根目录 `start-hosted-local.command`；若开发数据库缺少 Canvas 所需的 4 张表、32 个字段、14 个有效索引或 2 个已验证外键，启动器应只读检查后停止并提示受控迁移，绝不能自动执行主站全量结构同步。结构完整且唯一的 `jsermjc@sina.com` 正式账号处于活动状态后，`/api/canvas/v1/readiness` 必须返回 204，启动器才可报告成功并打开主站；随后以该账号登录主站并从 `/canvas` 打开画布，`/api/canvas/v1/auth/exchange` 应成功建立会话。图片输入面板首次打开且提示词为空时也应按当前参数调用一次 `/api/canvas/v1/quote` 并显示积分，连续输入提示词不应再次请求；修改模型、比例、清晰度或质量后各重新报价一次。分别验证文生图和上传参考图后的图生图；上传超过 3MB 但不超过 30MB 的参考图时，提交前应逐张压缩到 6MB 内且节点原图预览不变，不应再收到「单张参考图不能超过 6MB」；图生图控制台不应再出现 `blob:` 被 `connect-src` 拦截，积分报价与最终扣分仍按主站现有参数规则执行。
- 多图连线自动引用：新建一个空图片节点，依次把两张已有图片连接到它，提示词上方应依次出现两张独立缩略图；输入 `@` 应继续弹出可引用的节点列表，选择引用后在输入区显示对应节点。悬停缩略图应显示大图预览，点击缩略图右上角删除按钮后只断开对应来源连线。重复连接同一来源不得重复添加，输入提示词后生成应提交所有仍连接的参考图。
- 画布顶部操作：空画布列表不显示左上角「新建画布」，只保留空态中央的新建入口和标题，不再显示扩展创作过程的说明；创建首个画布后，左上角新建入口应出现。Hosted 列表页左上角以与主站头像等大的橙色 Logo 和「回到主页」替代主页图标、源码、协议和版本文字；进入画布编辑页后顶部导入、导出及收起工具栏完全隐藏，只保留左上角返回画布列表和与返回箭头等大的 Logo「回到主页」入口。
- Hosted 画布接入：使用超级管理员 `jsermjc@sina.com` 从 Visionary 主站打开画布，确认无需配置 API Key、Base URL 或模型渠道即可使用文本和图片生成；确认非 iframe、错误 nonce、错误来源、未登录、其他所有账号与功能未开放状态都会停在不可用页，且不能发起生成。等待超过 15 分钟后继续操作，确认票据会自动续期而不是强制退出；积分变化后确认主站余额会刷新。分别在 POST 已到服务端但响应断网、手动停止、刷新重开三种情况下确认节点显示「确认中」、不能重复提交，恢复始终复用同一 `clientOperationId` 且只扣一次积分；多图任务恢复首张成功图后，折叠根节点应同步出现主图，部分失败不应把已有成功主图改成错误。Hosted 页面只显示图片和文本入口，图片数量可选 1–4 张且每张继续按独立任务结算，4 张时浏览器最多同时提交 2 路请求；视频、音频、插件、Agent、WebDAV、API 配置与直连模型入口均不可用。画布列表和编辑页不再显示重复的右侧导航状态组，右上只由主站展示用户资料与积分。
- Hosted 任务恢复边界：文本任务一旦拿到 `runId`，模拟会话续期期间的 401/403、SSE 断线和短暂 5xx，节点必须继续显示「确认中」并在会话恢复后重连原 `runId`；取消接口返回 409 时不能立即显示已取消或退回积分。图片批次停止后，分别验证「已提交子图失败 + 未提交子图空闲」与「已提交子图仍确认中」两种组合，根节点应分别显示失败和确认中；刷新页面后不能重新提交已受理任务，即使项目快照尚未写入 `hostOperationId`，也应先从持久化操作记录恢复防重复锁再开放生成。构造同一画布至少 7 个待确认图片操作时，恢复器应按每批 6 个分批查询，后续操作不能被前 6 个长期任务饿死。关闭页面超过一天再打开，仍应能看到本地操作记录并继续确认，不能因为本地 TTL 静默丢失。
- Hosted 破坏性操作保护：图片或文本处于生成中/确认中时，删除相关节点、删除折叠批次根节点、删除上游参考节点、清空画布、撤销重做和替换图片都应被阻止；返回画布列表后删除该项目也应提示先完成恢复。任务终态写入 IndexedDB 失败时，本地 operation 不能被确认删除；恢复存储后应继续投递到原节点且只扣一次积分。
- 一键本地启动：macOS 双击仓库根目录的 `start-local.command`，应自动选择满足 Vite 要求的 Node.js，缺少依赖时自动安装，并在 `http://localhost:3002/canvas` 打开页面；端口已有服务时应直接复用，终端关闭后本次启动的开发服务器应同步退出。
- Visionary 品牌与链接：检查网页标题、画布库、文档站和 Codex 插件说明显示 Visionary Infinite Canvas，公共顶栏左上角不显示 Logo 和品牌文字，仅显示主页图标，右侧不显示 GitHub 图标，项目文档中的源码、上游归属与 AGPL 声明仍可访问；打版本标签后确认 GitHub Pages 的 `/visionary-infinite-canvas/`、`/canvas` 路由、Logo、模型图标和本地插件地址正常，并确认 Docker 镜像目标属于当前 Fork。
- 首页跳转：直接访问画布应用根路径 `/`，应立即替换为 `/canvas` 并显示「我的画布」页面，不再出现原首页展示内容；画布编辑页左上返回箭头应返回 `/canvas` 列表，「回到主页」应通过安全通道返回 Visionary 主站 `/`。
- 我的画布视觉：页面顶部不再显示「画布工作区」、大标题和说明文字，也不再显示「删除全部」；已有画布时，导入和新建按钮置于内容顶部左侧，选择画布后出现的批量操作保持同一左侧操作区；空列表时左上角不显示新建按钮。深色主题使用接近 `#050505` 的背景、白色高对比主按钮及带细边框和柔和阴影的 `28px` 大圆角画布卡片，浅色主题保持同样层级。空状态、新建、导入、选择、重命名、导出和单项/选中删除功能均应正常，所有可用功能按钮悬停时应显示小手指针。
- 画布深色工具条：切换深色主题后，选中空图片、已生成图片、文本和配置节点，验证紧凑及多按钮展开的节点操作工具条、按钮悬停态和 Tooltip 均为深色；切回浅色主题后应恢复浅色。
- 画布图片自动引用与尺寸继承：从一张已有内容且调整过尺寸的图片节点右侧拉线，在空白处选择「图片生成」，新图片节点应与上游节点宽高一致，且提示词上方自动显示上游图片缩略图，无需输入 `@`；删除缩略图后对应连线应同步断开，普通双击创建的图片节点不应自动添加引用。
- 图片裁剪与切图：Hosted 画布中对已有图片执行「裁剪」并确认、执行「切图」并生成子节点，均不应出现 `data:image/...` 被 CSP 拦截或 `Failed to fetch`；自定义图片工具栏中不应出现「锁比例」和「放大」，即使刷新前保存过旧快捷工具配置也应自动移除。
- 图片参考生成布局：新建图片节点并上传图片，调整节点尺寸后输入提示词生成一张或多张图片；生成中的结果节点应从原节点右侧留出间距开始排列，全部继承原节点宽高且不与原节点重叠，生成完成后尺寸和位置不应跳回默认值。
- 画布节点浮层尺寸：为图片节点开启全部快捷工具并选中节点，上方工具条宽度最多占浏览器视口的 60%，超出部分可横向滚动；打开节点下方参数面板后连续放大、缩小及平移画布，面板应继续跟随节点，但输入框、文字、按钮和整体宽高始终保持固定屏幕尺寸。
- 画布主背景：进入新建或已有画布项目，画布主区域应使用纯黑背景，原格线背景统一显示为比上一版更清晰的深灰色细小点阵；画布外观只保留「点 / 空白」选择，不显示线框选项和浅色/深色主题切换，框选区域仍应清晰可见。
- 画布节点裁剪：在包含远距离连接节点的画布上缩小视图并连续左右平移，处于屏幕内或屏幕边缘附近的节点不应突然消失，连线端点与节点应同步出现或离开；打开小地图后反复拖动视口也应保持一致。
- 画布连线交互：在不同缩放倍率下检查节点左右连接点均为 `22 × 22px` 圆形加号，且与图片边缘保持 `5px`；开始拉线时节点下方输入面板应暂时隐藏，连线完成或鼠标释放取消后恢复，节点上方工具栏应隐藏；双击空白处和节点连线创建应打开相同的文本、图片、视频、音频菜单，点击节点时创建菜单应关闭并只显示工具栏，创建菜单始终显示在节点输入面板上方。Hosted 菜单不显示配置节点，视频生成和音频生成保留为不可点击的置灰项，右侧以小号文字显示「即将上线」；底部工具栏显示视频、音频按钮，点击仅在按钮上方短暂提示「该功能即将上线」且不新增节点；右上角关闭图标更易点击和辨认。
- 文本节点三态：画布顶部不再显示「文档」；新建或点击文本节点后，下方自动显示固定屏幕尺寸的大圆角文本生成面板，空节点显示「双击开始编辑...」，生成时显示三行骨架动画，完成后在原节点内以较大字号显示结果；提示词、文本模型、单次生成标识及圆形生成/停止按钮应继续可用。
- 文本节点工具与引用：选中文本节点时，上方快捷工具栏不再显示「编辑」和「生图」，字号操作显示为「缩小字号」「放大字号」；从有内容的文本节点右侧拉线创建文本、图片、视频、音频或配置节点时，新节点输入区应自动出现该文本引用，无需再次手动输入 `@`。
- 文本与图片节点生成参数：点击图片节点后，下方提示词面板应加宽并将无图标模型、清晰度、比例、质量、数量、积分占位和发送保持在同一条无滚动底栏；数量可选择 1–4 张，旧画布保存的 5–9 张应自动按 4 张报价和执行。GPT Image 2 的比例应为 Auto、1:1、3:2、2:3、4:3、3:4、16:9、9:16、21:9、9:21、2:1、1:2、5:4、4:5、3:1、1:3；Nano Banana Pro 与 Nano Banana 2 Lite 应按主站能力改为 Auto、1:1、4:3、3:4、3:2、2:3、16:9、9:16、21:9、5:4、4:5、1:4、4:1、1:8、8:1。切换模型后旧比例若不受支持，应自动切换到该模型首个合法比例，不能把不支持的比例提交到接口。质量提供自动、低、中、高，模型下拉项和比例入口均不显示图标。未选择时默认显示标准、1:1、自动；切换选项并刷新后应回显节点上次选择。GPT Image 2 在标准清晰度下不显示质量并按自动质量提交，切换到 2K/4K 后恢复；Nano Banana Pro 选择「标准」时应按主站下发的最低合法清晰度请求报价与生成，积分应显示 20 而不是 `--`；`nano-banana-2-lite` 出现在模型选择中，固定按标准/1K 提交并隐藏不可用的 2K/4K 选择，固定「标准」文字应与其他模型清晰度值字号一致；Banana、Nano Banana 及对应 Gemini Image 系列模型始终不显示质量，其他模型仍显示。Hosted 文本模型内部键 `chat-pro` 应显示主站下发的 `gpt-5.5` 标签，选择和请求仍使用内部键；右键菜单应始终覆盖节点提示词面板。自定义尺寸入口不再出现，原有透明背景开关仍可从更多参数入口使用。文本节点只显示自身支持的无图标模型、固定数量、积分占位和发送。
- Hosted 品牌入口：图片和文本生成按钮左侧的积分图标应显示橙色 Visionary 厨师帽 Logo；画布列表和编辑页左上角显示同一 Logo 与「回到主页」，点击后应通过已校验的主站安全通道返回主站 `/`，不能在 iframe 内打开第二份主站页面；编辑页 Logo 左侧应额外显示返回箭头并返回画布列表。
- Hosted 发布顺序：先发布主站，并确认 `https://canvas.visionary.beer/api/canvas/v1/readiness` 返回 204、Canvas API、Shell、返回主页消息和 Lite 模型能力均正常，再发布画布静态站；发布画布前先把 `ops/nginx/visionary-canvas-security-headers.conf` 安装到服务器，执行 `nginx -t` 并 reload。若线上 CSP 缺少 `connect-src 'self' blob:`，画布部署脚本必须在切换静态版本前阻断；回滚时不能只回滚主站而保留依赖新协议的新画布。根目录 Dockerfile 与两份 Vercel 配置构建的是独立版应用，不包含生产 Hosted 的安全别名、Canvas API 反向代理和发布元数据，禁止用它们替代 `npm run deploy:hosted` 发布生产画布。
- 批量图片主图：展开多张生成结果，单击任一子图时只能用于选择主图，不应显示普通节点工具栏或下方输入面板；点击「设为主图」后根节点应立即切换为该图片、清理隐藏选中态并播放收起动画，最终只显示带数量角标的堆叠主图。批量根节点处于折叠状态时，单击根节点应正常显示下方输入面板，模型、参数、参考图和生成操作均保持可用。两图批次删除任一子图后应自动解散为普通根节点，刷新仍显示保留图片；保留子图原本连接的下游节点与 Config `@[node:...]` 引用必须迁移到根节点，不能丢失或残留旧 ID。
- 全站开关开启态：分别在浅色和深色主题下检查配置弹窗、提示词来源、Agent 工具确认、插件、画布图片信息及图片/视频设置中的开关；所有开启状态均应使用绿色背景，关闭和禁用状态保持原有层级。
- 画布提示词与工具栏：在已有内容的图片节点参数面板输入提示词，关闭并重新打开后内容应保留；使用中文输入法开始输入时，占位文字应立即消失，不与拼音或候选文字重叠；快捷工具设置不再显示节点预览模块和超分选项，其他工具仍可勾选保存；节点上方相邻工具项内容间距约为一个字号。
- 画布栏位折叠：左侧面板的展开/收起按钮应紧贴画布最左边缘并保持页面垂直居中；按钮左边框及面板右边框与按钮等长的区段应消失，按钮和面板视觉连为一体，面板收起后不应残留内侧边框；底部主工具栏最右侧应显示「双下箭头 + 收起」，收起后仅保留双上箭头，刷新页面后保持上次状态；侧栏和底栏收起后的独立展开按钮均使用橙色背景和白色箭头。
- 画布折叠按钮尺寸：底部主工具栏收起后，独立展开按钮应为约 `60 × 28px` 并紧贴页面底边；左侧面板开关应使用对应的约 `28 × 60px` 竖向尺寸。左侧、顶部和底部的展开/收起按钮均使用 `3px` 圆角，顶部与底部收起态不显示内边框和阴影。
- 画布左侧开关图标：左侧面板展开时显示单线向左箭头，收起时显示单线向右箭头，图标样式应与顶部和底部工具栏的上下箭头一致。
- 画布顶部功能组：编辑页不再显示导入资产、导出当前画布、插件、配置、快捷键及顶部展开/收起按钮；原有生成、侧栏、底栏和缩放操作保持可用。
- 画布快捷键说明：弹窗顶部不再显示拖动画布、滚轮和缩放滑杆三行；首行应显示「按住 Ctrl（win）/command（mac） + 鼠标左键」对应「框选多个节点」。

- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
