# 待测试

- 一键本地启动：macOS 双击仓库根目录的 `start-local.command`，应自动选择满足 Vite 要求的 Node.js，缺少依赖时自动安装，并在 `http://localhost:3002/canvas` 打开页面；端口已有服务时应直接复用，终端关闭后本次启动的开发服务器应同步退出。
- Visionary 品牌与链接：检查网页标题、画布库、文档站和 Codex 插件说明显示 Visionary Infinite Canvas，公共顶栏左上角不显示 Logo 和品牌文字，仅显示主页图标，右侧不显示 GitHub 图标，项目文档中的源码、上游归属与 AGPL 声明仍可访问；打版本标签后确认 GitHub Pages 的 `/visionary-infinite-canvas/`、`/canvas` 路由、Logo、模型图标和本地插件地址正常，并确认 Docker 镜像目标属于当前 Fork。
- 首页跳转：直接访问根路径 `/`，应立即替换为 `/canvas` 并显示「我的画布」页面，不再出现原首页展示内容；画布顶部的「主页」入口也应返回该页面。
- 我的画布视觉：页面顶部不再显示「画布工作区」、大标题和说明文字，也不再显示「删除全部」；导入和新建按钮置于内容顶部左侧，选择画布后出现的批量操作保持同一左侧操作区。深色主题使用接近 `#050505` 的背景、白色高对比主按钮及带细边框和柔和阴影的 `28px` 大圆角画布卡片，浅色主题保持同样层级。空状态、新建、导入、选择、重命名、导出和单项/选中删除功能均应正常，所有可用功能按钮悬停时应显示小手指针。
- 画布深色工具条：切换深色主题后，选中空图片、已生成图片、文本和配置节点，验证紧凑及多按钮展开的节点操作工具条、按钮悬停态和 Tooltip 均为深色；切回浅色主题后应恢复浅色。
- 画布图片自动引用与尺寸继承：从一张已有内容且调整过尺寸的图片节点右侧拉线，在空白处选择「图片生成」，新图片节点应与上游节点宽高一致，且提示词输入框自动显示上游图片缩略图引用，无需输入 `@`；退格删除引用后仍可改为纯文本提示词，普通双击创建的图片节点不应自动添加引用。
- 图片参考生成布局：新建图片节点并上传图片，调整节点尺寸后输入提示词生成一张或多张图片；生成中的结果节点应从原节点右侧留出间距开始排列，全部继承原节点宽高且不与原节点重叠，生成完成后尺寸和位置不应跳回默认值。
- 画布节点浮层尺寸：为图片节点开启全部快捷工具并选中节点，上方工具条宽度最多占浏览器视口的 60%，超出部分可横向滚动；打开节点下方参数面板后连续放大、缩小及平移画布，面板应继续跟随节点，但输入框、文字、按钮和整体宽高始终保持固定屏幕尺寸。
- 画布主背景：进入新建或已有画布项目，画布主区域应使用纯黑背景，原格线背景统一显示为细小的浅灰色点阵；画布外观只保留「点 / 空白」选择，不显示线框选项和浅色/深色主题切换，框选区域仍应清晰可见。
- 画布连线交互：在不同缩放倍率下检查节点左右连接点均为 `22 × 22px` 圆形加号，且与图片边缘保持 `5px`；开始拉线或弹出创建菜单时节点上方工具栏应隐藏，点击节点时创建菜单应关闭并只显示工具栏；菜单中的「文本生成」「配置节点」不再显示说明文案，右上角关闭图标更易点击和辨认。
- 文本节点三态：画布顶部不再显示「文档」；新建或点击文本节点后，下方自动显示固定屏幕尺寸的大圆角文本生成面板，空节点显示「双击开始编辑...」，生成时显示三行骨架动画，完成后在原节点内以较大字号显示结果；提示词、文本模型、单次生成标识及圆形生成/停止按钮应继续可用。
- 文本节点工具与引用：选中文本节点时，上方快捷工具栏不再显示「编辑」和「生图」，字号操作显示为「缩小字号」「放大字号」；从有内容的文本节点右侧拉线创建文本、图片、视频、音频或配置节点时，新节点输入区应自动出现该文本引用，无需再次手动输入 `@`。
- 全站开关开启态：分别在浅色和深色主题下检查配置弹窗、提示词来源、Agent 工具确认、插件、画布图片信息及图片/视频设置中的开关；所有开启状态均应使用绿色背景，关闭和禁用状态保持原有层级。
- 画布提示词与工具栏：在已有内容的图片节点参数面板输入提示词，关闭并重新打开后内容应保留；使用中文输入法开始输入时，占位文字应立即消失，不与拼音或候选文字重叠；快捷工具设置不再显示节点预览模块和超分选项，其他工具仍可勾选保存；节点上方相邻工具项内容间距约为一个字号。
- 画布栏位折叠：左侧面板的展开/收起按钮应紧贴画布最左边缘并保持页面垂直居中；按钮左边框及面板右边框与按钮等长的区段应消失，按钮和面板视觉连为一体，面板收起后不应残留内侧边框；底部主工具栏最右侧应显示「双下箭头 + 收起」，收起后仅保留双上箭头，刷新页面后保持上次状态。
- 画布折叠按钮尺寸：底部主工具栏收起后，独立展开按钮应为约 `60 × 28px` 并紧贴页面底边；左侧面板开关应使用对应的约 `28 × 60px` 竖向尺寸。左侧、顶部和底部的展开/收起按钮均使用 `3px` 圆角，顶部与底部收起态不显示内边框和阴影。
- 画布左侧开关图标：左侧面板展开时显示单线向左箭头，收起时显示单线向右箭头，图标样式应与顶部和底部工具栏的上下箭头一致。
- 画布右上角功能组：展开态只显示主页、导入资产、导出当前画布、插件、配置、快捷键和收起按钮，隐藏 GitHub、Agent 与主题切换按钮；配置及其他可用操作悬停时显示小手指针。点击收起后应只保留展开按钮，刷新页面后保持上次状态。
- 画布快捷键说明：弹窗顶部不再显示拖动画布、滚轮和缩放滑杆三行；首行应显示「按住 Ctrl（win）/command（mac） + 鼠标左键」对应「框选多个节点」。
- 画布响应式工具栏：缩放控制应位于页面右下角，底部主工具栏应以页面中线居中，并通过左右对称预留空间避免与缩放控制重叠；缩小浏览器窗口后，底部两组控件和顶部功能组应同步缩小；顶部所有入口应共用一个边框，不再显示画布名称、Codex 连接状态、三横线菜单、我的画布、新建画布、删除当前画布及顶部撤销/重做，展开态最右侧显示「双上箭头 + 收起」，收起后仅保留双下箭头的直角按钮并紧贴页面顶边；快捷键弹窗应为横向宽屏双列布局，小屏时回落为单列并可内部滚动。
- 提示词来源：6 个内置来源应从 Image Prompts 统一仓库读取，更新后数量依次为 323、494、53、76、126、129；提示词仍按 6 个来源分组并可独立启用，来源内可继续按 `tags` 筛选。添加标准 JSON URL 后应能查看内容，填写非数组 JSON 或不可访问地址时应显示失败，并继续保留该来源上一次成功缓存的内容。
- 提示词来源界面：来源应以卡片列表展示，启用开关位于左侧，数量、同步状态和上次成功时间作为次级信息显示，查看、拉取及自定义来源编辑/删除操作使用带文字按钮；底部定时拉取区域应保持独立边框布局。
- 提示词收藏：页面不再显示「灵感资料库」和「提示词中心」标题区；提示词库与收藏 Tab 字号加大，当前提示词数量显示在 Tab 下方。提示词库采用左侧筛选、右侧提示词卡片的分栏布局；左栏搜索和分类保持固定，标签可视区域高度约为原来的两倍，只有标签区域可以上下滚动且不能左右滚动，较长标签应自动换行；卡片操作按「复制、收藏、加入资产」显示。切换到「收藏」后验证新增、编辑、删除和搜索；收藏的提示词应出现在收藏列表、画布左侧提示词面板和提示词选择弹窗中，刷新页面后数据仍保留在本地，Agent 搜索提示词时也应能查到。
- 全站 Visionary 视觉：分别打开我的画布和我的资产，验证页面使用连续背景、半透明大圆角表面、细边框、高对比按钮和柔和阴影；我的资产不再显示大标题与说明区。页面顶部与内容区共用连续背景和渐变，不应出现独立黑色色带、分隔线或模糊效果；左侧仅显示主页图标，右侧按「我的画布、我的资产、配置」排列，不显示 Logo、品牌名、生图、视频、提示词、GitHub 和主题切换入口，且不显示版本号；两个业务按钮应与「配置」使用相同字号和字重，并保留共用圆角底槽，进入对应页面时当前按钮显示橙色渐变背景和白色文字，切换页面时橙色滑块应在等宽按钮之间平滑移动且按钮本身不跳动；系统开启“减少动态效果”时应取消移动动画。配置按钮悬停时应显示小手，点击后继续打开完整配置弹窗，直接访问 `/config` 应跳转到 `/canvas`。检查 Agent 面板、Modal、Drawer、Popover、Dropdown 和 Select 浮层风格一致，小屏业务入口收敛为图标且不产生横向滚动。
- 画布双击创建菜单：双击画布空白处后，菜单不应显示「生成配置」和「组」，文本、图片、视频、音频及允许创建的插件节点仍可正常添加；底部工具栏与连线创建菜单保持原有能力。
- 画布提示词库：不展开任何公共来源直接搜索其中的提示词，匹配项应自动显示；点击「插入画布」后应创建正文正确且标题保持为提示词标题的文本节点。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
